# 터널 출구 보정을 GPS 복귀 승인까지 유지

2026-10-18 요청 범위: 출구 방향 보정의 종료 조건만 수정했다.

출구 전 기존 시작 구간에 들어오면 `exit_rejoin_active`를 설정한다. 이후 LiDAR 추정 진행이 출구 앵커를 지나 남은 거리가 음수가 되어도 기존 경로 방향과 센서 헤딩을 이용한 보정을 유지한다. 기존 `DrivingState.select()`가 GPS 모드를 승인한 뒤에만 해제한다. 단순히 GPS 메시지가 유효해지거나 불일치 GPS가 잠깐 들어오는 것으로는 해제하지 않는다. 상태 갱신과 해제는 같은 잠금을 사용한다.

기존 시작 구간, 보정 강도 계산, GPS 복귀 승인 조건, 센서 이상 정지, 음영 주행 허용 구간은 유지한다. 장애물 인지·회피, 벽 간격 복귀 제어, 고주로 코드와 설정은 변경하지 않았다. 터널 내부 비틀거림 전체를 해결하는 수정은 아니다.

검증: 출구·GPS 복귀·LiDAR 상태기 및 기존 출구 장애물 회피 관련 42개 테스트 통과. 추정 출구 통과 후 보정 유지, 일시적인 불일치 GPS에서 유지, 승인 후 해제와 다음 접근 초기화, 센서 이상 및 구간 이탈 시 정지 출력을 확인했다. 별도 소스·설정 732개 파일의 해시가 작업 전과 동일하다. 문법 검사와 `git diff --check`, 롤백 역적용·재적용 검사를 통과했다. 실제 MORAI 주행은 수행하지 않았다. 상세 결과는 [검증 기록](2026-10-18_exit_guidance_hold_validation/verification.json), [테스트 로그](2026-10-18_exit_guidance_hold_validation/targeted_tests.log)에 있다.

적용: 실행 중인 노드를 종료하고 이 워크스페이스 환경에서 `roslaunch unita_launch semi.launch`로 다시 시작한다. 해당 launch는 수정한 `driving_state_node_local.py`를 직접 실행한다. Python 변경이므로 별도 빌드는 필요 없다.

이번 수정만 되돌릴 때는 노드를 종료한 후 워크스페이스 루트에서 실행한다.

```bash
git apply --check -R rollback/2026-10-18_exit_guidance_hold.patch
git apply -R rollback/2026-10-18_exit_guidance_hold.patch
```

이 패치는 이번 노드·회귀 테스트 변경만 포함한다. 작업 전 파일은 `2026-10-18_exit_guidance_hold_before/`에 보관했다. 이후 같은 코드가 변경되어 사전 검사가 실패하면 강제로 덮어쓰지 않는다.

## CP10~CP11 장애물 판단 거리 — 설명만, 변경 없음

`semi.launch`는 고주로 구간을 S11로 설정한다. 고주로 앞차 판단은 `highway_obstacle_horizon_m=55m`를 사용한다. 패널에 보이는 일반 `obstacle_horizon_m=45m`와 별개다. 기록된 `run_20261018_223827/rosparams.yaml`에서도 각각 55m와 45m, `highway_sectors: '11'`을 확인했다. 전방 LiDAR 물체 검출 범위의 기본값도 55m이다.

현재 경로 시각화 메시지의 `horizon_m` 숫자에는 고주로 여부와 무관하게 일반 45m 값이 실린다. 고주로 경로 점들은 전용 거리로 생성되므로 숫자와 실제 범위가 다르게 보일 수 있다. 표시 코드도 이번에는 변경하지 않았다.

55m 안에 앞차가 있다는 이유만으로 감속하지는 않는다. 현재 고주로 추종은 범퍼 간격과 상대속도에 따라 감속을 계산한다. 같은 속도로 달리는 앞차는 멀리 보이더라도 그 이유만으로 감속하지 않으며, 느린 차·정지 물체·속도가 미확정인 물체를 빠르게 따라잡는 경우에는 일찍 감속할 수 있다. 차선 끝이나 곡률에 따른 별도 제한도 있다. 거리 설정만으로 사용자가 느낀 조기 감속의 원인을 확정할 수는 없다.

향후 더 늦은 반응을 시험하려면 일반 45m가 아니라 고주로 전용 55m를 조정해야 한다. 다만 범위를 줄이면 추월 판단도 늦어지고 느린 앞차를 발견한 뒤 필요한 제동이 강해질 수 있다. 부드러움까지 원한다면 먼저 해당 감속 시점의 앞차 상대속도와 제한 원인을 비교해 조정하는 편이 적절하다. 이번에는 어느 거리나 추종 설정도 수정하지 않았다.
